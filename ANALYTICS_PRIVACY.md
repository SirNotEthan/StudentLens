# Analytics & Privacy Policy

## Overview

StudentLens implements comprehensive analytics tracking to improve user experience, understand feature usage, and optimize platform performance. This document explains what data we collect, how we use it, and your privacy rights.

## Data Collection

### Automatically Collected Data

When you use StudentLens, we automatically collect the following information:

#### Technical Data
- **IP Address**: Used for security, spam prevention, and geographic analytics
- **Browser Type & Version**: Chrome, Firefox, Safari, Edge, etc.
- **Device Type**: Desktop, Mobile, or Tablet
- **Operating System & Version**: Windows, macOS, iOS, Android, Linux
- **User Agent String**: Technical browser/device information

#### Usage Data
- **Pages Viewed**: URLs and page titles you visit
- **Posts Viewed**: Articles you read
- **Session Information**: Session duration and frequency
- **Referrer**: Where you came from to reach our site

### User-Generated Events

We track the following user actions:

- **Content Interactions**:
  - Post views, likes, and unlikes
  - Bookmarks (save/unsave)
  - Comments created and liked

- **Content Creation**:
  - Post creation, editing, and deletion
  - Profile updates

- **Search Activity**:
  - Search queries
  - Search result counts

- **Feature Usage**:
  - Which features you interact with
  - Navigation patterns

- **Account Activity**:
  - Login/logout events
  - Account registration
  - Session duration

## How We Use This Data

### Platform Improvement
- Understand which features are most/least used
- Identify navigation issues and user experience problems
- Optimize page load times and performance
- Detect and fix bugs based on usage patterns

### Analytics & Insights
- Generate aggregate statistics (total users, page views, etc.)
- Understand content popularity
- Analyze user engagement trends
- Create user behavior reports for administrators

### Security & Fraud Prevention
- Detect suspicious activity patterns
- Prevent spam and abuse
- Monitor for security threats
- Rate limiting and access control

## Data Storage & Retention

### Storage Location
All analytics data is stored securely in our Appwrite database with the following protections:
- Encrypted at rest
- Access-controlled (only authorized administrators)
- Regular backups

### Retention Period
- **Active Users**: Analytics data retained for 90 days
- **Inactive Users**: Data anonymized after 6 months of inactivity
- **Aggregated Data**: May be retained indefinitely for trend analysis

### Data Deletion
Users can request deletion of their analytics data by:
1. Contacting support
2. Deleting their account (removes all associated analytics)

## Privacy Controls

### What You Can Control

#### Opt-Out Options
While we don't currently support complete analytics opt-out (as it's essential for platform security and functionality), you can:
- Clear your browser cookies regularly
- Use private/incognito browsing mode (creates anonymous sessions)
- Request deletion of your historical data

#### Data Access
You can view your own analytics data by:
1. Navigating to the Analytics page
2. Viewing the "Your Activity Insights" section
3. Contacting support for a complete data export

### What We DON'T Collect
- **No Third-Party Tracking**: We don't use Google Analytics, Facebook Pixel, or similar third-party trackers
- **No Personal Messages**: We never track or store the content of private messages or comments
- **No Password Information**: Passwords are never logged or tracked
- **No Financial Data**: No credit card or payment information (if applicable)

## Administrator Access

### Who Can See Analytics Data

#### Your Personal Data
- **You**: Can see your own activity insights
- **Administrators**: Users with `view_analytics` permission can see:
  - Aggregate statistics (total counts, averages)
  - Anonymous user behavior patterns
  - System-wide analytics
  - Individual user data (only when investigating issues or abuse)

#### What Administrators See
Administrators with analytics permissions can view:
- Total events and unique users
- Device, browser, and OS statistics
- Top pages and posts
- User growth trends
- Feature usage statistics

## Technical Implementation

### Data Minimization
We follow the principle of data minimization:
- Only collect data necessary for platform operation
- Automatically aggregate and anonymize where possible
- Remove personally identifiable information from long-term storage

### Security Measures
- All API endpoints are authenticated
- Analytics data access requires specific permissions
- Analytics tracking failures never break the user experience
- IP addresses are hashed for privacy when used in analytics

## Compliance

### GDPR Compliance
- **Right to Access**: Request your analytics data
- **Right to Deletion**: Request deletion of your analytics data
- **Right to Rectification**: Correct inaccurate data
- **Right to Portability**: Export your data in a machine-readable format

### CCPA Compliance
- **Do Not Sell**: We NEVER sell your analytics data to third parties
- **Data Categories**: All collected categories are listed in this document
- **Business Purpose**: Used only for platform improvement and security
